# RFM69 File Transfer


## Environment 

- Ubuntu 24.04.3 LTS (WSL)
- Python: 3.10+ (tested w/ 3.12.3) (venv)

### Current Files

#### Shared
- `checksum.py`
    computes md5 checksum for a file to verify integrity.

- `chunking.py`
    splits folder into 60-byte chunks for transmission and writes to new folder.

#### Output

- `rfm69_transfer/output/`
    - `sent_chunks.bin`
    - `start_header.txt`
    - both files in Output folder are generated by `sender.py` or `sender_eth.py`
